The easiest way to start
GSoC & open source contributions

1. Run GSoC Project Matcher

Run contrib recommend to take a 10-second interactive quiz. Filter by your tech stack (Python, JS, C++, Rust), available hours, and beginner friendliness ratings.

2. Sub-Second Blobless Clone

Skip waiting 5+ minutes for massive repository histories. contrib clone uses Git blobless checkouts (--filter=blob:none), fetching commit trees on demand and saving 98.8% bandwidth.

3. Auto AI Context (.contrib)

Every workspace automatically creates a .contrib/ directory with ISSUE.md and AI_PROMPT.md. Pass it directly to Antigravity, Cursor, or Claude Code for instant bug fixes!

4. Per-Workspace SSH Identity

Isolate your open-source Git commits from your personal or work accounts cleanly. contrib ssh manages author email and SSH keys per workspace without global config corruption.

5. Go Live & Submit PR!

Your blobless workspace is configured and AI context is loaded. Start coding and push your pull request with confidence.
